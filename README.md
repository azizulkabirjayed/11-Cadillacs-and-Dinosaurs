# About The Project

**Cadillacs and Dinosaurs** is a 3D action game built with Python and OpenGL as part of the CSE423 (Computer Graphics) course at BRAC University. Players fight through waves of enemies across multiple zones, using punches, jump attacks, and spinning kicks to survive. The game features a boss fight, collectibles, a day–night cycle with snow effects, and switchable camera modes. This project was developed as part of the CSE423(Computer Graphics) course project at BRAC University.

# Features
* 3D OpenGL action game built with Python & PyOpenGL
* Multiple enemy types & boss fight
* Zone-based progression system
* Punch, jump attack & spinning kick combat
* Player health, scoring & collectibles
* Obstacles (trees, cars) with collision detection
* Day–night cycle with Snow particle effects
* Third-person & first-person camera modes & camera movement
* Cheat mode with bomb attacks
* Pause, restart & in-game UI controls

# Controls
| Key | Action |
|----|-------|
| W | Move Forward|
| A | Move Backward|
| S | Move Left|
| D | Move Right|
| Left Mouse Button | Punch |
| Space | Jump |
| Space+Left Mouse Button | Jump Attack |
| Space+Right Mouse Button | Spinning Kick |
| C | Toggle Cheat Mode |
| Q | Toggle First-Person/Third-Person Camera |
| →/ ←/ ↑/ ↓ | Rotate Third-Person Camera Left/ Right/ Up/ Down |
| R | Restart(after game over) |

# How To Run

Make sure you have **Python 3.x** and **pip** installed, then follow these steps:

```bash
# 1. Clone the repository
git clone https://github.com/<your-username>/Cadillacs-and-Dinosaurs.git
cd Cadillacs-and-Dinosaurs

# 2. Install dependencies
pip install PyOpenGL PyOpenGL_accelerate

# 3. Run the game
python project_code.py
```

The game window will open and you're good to go — see the [Controls](#controls) section below to start playing.
